# Public showcase roadmap

This is a public demonstration roadmap, not a private product plan.

- **Available now:** synthetic DEM, raster metadata, explicit metric-unit checks, AOI masking, terrain descriptors, contours, JSON summary, and analytical tests.
- **Candidate public additions:** small openly licensed raster examples with attribution, reproducible metadata fixtures, and accessible map presentation.
- **Outside this repository:** private providers, municipality or client workflows, production deployment, proprietary engineering and ML logic, model weights, and large LiDAR archives.

A published research or engineering result would need verified source rights, declared surface and vertical references, independent validation data where accuracy is claimed, stated method limits, and human review.
