# Synthetic spatial inputs

`synthetic_dem.tif` and `example_aoi.geojson` are generated by `examples/make_synthetic_dem.py`. The DEM is a 128×128, 10 m grid in EPSG:32614 with an intentional NoData patch. Elevation is an arbitrary mathematical surface, not a survey of the encoded map location. The AOI is a WGS84 polygon covering part of that grid. Neither file contains third-party or client data.
